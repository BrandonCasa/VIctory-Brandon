# Findings priority checklist

**Start with [rank 1](pipeline-retain-commands-until-first-use-pso-is-ready.md) if you’re choosing a first change.** It protects both visible draws and one-time work, such as a lighting bake.

Rank expresses impact and confidence. Independent fixes can land in parallel. Pull a lower-ranked item forward when it supplies something the higher-ranked fix needs. For example, take the BVH landing and refresh changes ([rank 6](memory-publish-bvh-landing-writes-in-command-order.md) and [rank 7](submit-order-refreshes-around-bvh-landing-writes.md)) together as part of [rank 2](lighting-publish-complete-bvh-builds-before-tracing.md). The archive decode fix ([rank 9](dstorage-decode-zlib-archive-swizzle-modes.md)) can ship independently. Check off each item when its finding’s expected result holds.

Ranks 1–27 cover correctness. Ranks 28–73 cover deferred performance changes, ordered by evidence of use in the title, work avoided and implementation cost. Their FPS impact is unmeasured. The final entry records a proposal already ruled out for the captured shaders.

- [ ] **1.** [Keep draws and dispatches whose pipelines are still compiling](pipeline-retain-commands-until-first-use-pso-is-ready.md) — The cutscene log records thousands of dropped commands per frame during compilation. The cache work at [rank 22](pipeline-restore-graphics-psos-from-exact-cache-recipes.md) and [rank 23](pipeline-resolve-cached-compute-psos-from-title-description.md) can reduce the stall.
- [ ] **2.** [Restore the scene geometry used by lighting rays](lighting-publish-complete-bvh-builds-before-tracing.md) — The default builder path is off. Deliver this with [rank 1](pipeline-retain-commands-until-first-use-pso-is-ready.md), [rank 5](lighting-map-reachable-bvh-pages-before-first-access.md) and [rank 8](lighting-publish-compacted-bvh-size-at-guest-completion.md), pulling in [rank 6](memory-publish-bvh-landing-writes-in-command-order.md) and [rank 7](submit-order-refreshes-around-bvh-landing-writes.md) for streamed geometry. Switch the lighting output at [rank 14](lighting-use-title-probe-resolve-for-diffuse-light.md) once its inputs work.
- [ ] **3.** [Run the three refused wave64 compute shaders on wave32 GPUs](shader-emulate-wave64-compute-on-wave32.md) — The RTX capture identifies three actual PSO refusals. Exact lowering restores a path for particle visibility, VFX relocation and transmission filtering. This can proceed alongside [rank 1](pipeline-retain-commands-until-first-use-pso-is-ready.md).
- [ ] **4.** [Use the same descriptor address for memory preparation and shader binding](draw-snapshot-descriptor-addresses-per-stage-bind.md) — A descriptor rewrite can make one dispatch prepare one address and read another. - [ ] **5.** [Make every reachable BVH page available on first access](lighting-map-reachable-bvh-pages-before-first-access.md) — An absent page returns zero or loses a store. Later residency cannot repair that ray or build. Pair with [rank 2](lighting-publish-complete-bvh-builds-before-tracing.md) and the upload boundaries at [rank 6](memory-publish-bvh-landing-writes-in-command-order.md)–[rank 7](submit-order-refreshes-around-bvh-landing-writes.md).
- [ ] **6.** [Publish streamed BVH bytes and their page-directory entries together](memory-publish-bvh-landing-writes-in-command-order.md) — A familiar header can hide a changed payload. Honor the preceding guest writes and retain the version each builder reads. Land this with [rank 7](submit-order-refreshes-around-bvh-landing-writes.md).
- [ ] **7.** [Keep refresh planning on the correct side of each BVH upload](submit-order-refreshes-around-bvh-landing-writes.md) — This is the submission half of [rank 6](memory-publish-bvh-landing-writes-in-command-order.md). A later landing must never overwrite the version an earlier dispatch still needs.
- [ ] **8.** [Publish the compacted BVH size before the game allocates its destination](lighting-publish-compacted-bvh-size-at-guest-completion.md) — A stale size can let compaction overwrite neighboring geometry. Include this feedback path when enabling dynamic builds at [rank 2](lighting-publish-complete-bvh-builds-before-tracing.md).
- [ ] **9.** [Decode the archive builder’s zlib swizzle modes](dstorage-decode-zlib-archive-swizzle-modes.md) — The executable emits flags the fork rejects. This is an independent streaming fix that can restore asset bytes before any rendering work lands.
- [ ] **10.** [Track which physical bytes back each streamed texture subresource](texture-track-subresource-backing-across-remaps.md) — An equal-size remap can keep a stale mip or slice alive. Share backing identity and generation with [rank 11](texture-publish-writes-across-backing-aliases.md).
- [ ] **11.** [Make texture writes visible through every alias](texture-publish-writes-across-backing-aliases.md) — Periodic fingerprints can miss writes outside their sample windows. Use [rank 10](texture-track-subresource-backing-across-remaps.md) for remaps, [rank 21](xmem-notify-aliases-of-written-physical-byte-ranges.md) for physical writes and [rank 18](texture-upload-completed-bink-frame-planes.md) for decoder-owned planes.
- [ ] **12.** [Give placed texture UAVs and their readers the same backing](texture-share-placed-uav-writes-with-alias-readers.md) — The fork excludes real nonzero placed texture UAVs. This supports [rank 14](lighting-use-title-probe-resolve-for-diffuse-light.md) when the title’s resolve writes through one. The zero-address warnings alone do not identify a broken shot.
- [ ] **13.** [Map the entire guest descriptor heap to valid host slots](bindless-map-full-guest-view-heap-to-host-slots.md) — Valid high indices can reach scratch or null. Share the binding generation from [rank 4](draw-snapshot-descriptor-addresses-per-stage-bind.md). Use the mapping for indexed views in [rank 15](draw-bind-exact-bytes-for-unaligned-cbvs.md) and [rank 16](bindless-preserve-byte-offsets-in-buffer-views.md).
- [ ] **14.** [Use the title’s probe resolve for final diffuse lighting](lighting-use-title-probe-resolve-for-diffuse-light.md) — Removing the ambient substitute by itself can darken interiors. Land the visible switch with working geometry from [rank 2](lighting-publish-complete-bvh-builds-before-tracing.md) and the correct output from [rank 12](texture-share-placed-uav-writes-with-alias-readers.md) where applicable.

- [ ] **30.** [Select only the texture slots the upload pass can service](deferred/texture-select-only-due-slots-within-upload-budget.md) — Large backlogs pay for sorting entries beyond the quota. Preserve retry order while bounding the sort to the returned work.

- [ ] **36.** [Maintain relay write coverage as flights enter and leave](deferred/relay-maintain-write-coverage-per-flight.md) — Cuts repeated work under a lock shared with submitters. - [ ] **38.** [Reject textures with no usable cache key before copying them](deferred/texture-store-reject-uncacheable-mip-prefixes-early.md) — Avoids hashing, copying and queuing an entire payload that the store would discard. - [ ] **39.** [Keep original CPU bytes through shadow copyback](deferred/copyback-reuse-original-title-bytes-during-shadow-merge.md) — Removes reconstruction and a temporary allocation for changed intervals while preserving the title-wins merge.
